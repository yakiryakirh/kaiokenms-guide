How this Database works

The public GMS v83 explorer is loaded from MapleStory.IO. This editor controls only the KaiokenMS layer: custom items, NPCs, features, corrections, images and server notes.

Use Disable instead of Delete when you may want the record back. Uploaded images are stored in the public guide-database-images bucket, but only staff can upload, replace or delete them.
