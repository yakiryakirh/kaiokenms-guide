🔥 EXP & Drop Events

Only confirmed staff announcements are treated as event times.

Current schedule status

No fixed repeating 2x EXP schedule is verified yet. The announcement log shows different event windows, including one event started for the next two hours and another explicit 11:00 to 15:00 UTC window.

No repeating 2x Drop server event was found in the announcement log provided so far. 2x Drop coupons sold by NPCs are separate from server wide events.

Verified event history

  • 11 Aug 2026: Double EXP announced for the next 2 hours at 18:45 UTC.
  • 14 Aug 2026: Double EXP explicitly announced for 11:00 to 15:00 UTC.
  • Later community messages mention extra Double EXP around restarts and updates, which points to staff triggered events rather than a fixed weekly timer.
